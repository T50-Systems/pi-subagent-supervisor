# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-07-16

### Added
- Runtime supervision for turns, tool starts, lifetime tokens, and wall-clock duration.
- Balanced general and Plan-specific default budgets.
- Graceful turn/tool wrap-up steering followed by automatic RPC cancellation.
- Resume monitoring with per-invocation usage baselines.
- Global and project configuration with enforce, warn, and off modes.
- Privacy-minimized limit events and a `/subagent-supervisor` status command.
